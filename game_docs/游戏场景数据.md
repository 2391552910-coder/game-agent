## 2. 动作枚举白名单数据
- `move_to`：移动技能，参数需包含 `target` 坐标(x,y,z) 和 `speed`(可选 walk 或 run)。
- `play_action`：执行基础动作技能，参数需包含 `name`，可选枚举值有：
  - `wave`：挥手，无限制。
  - `sit`：坐下，无限制。
  - `stand_up`：起立，无限制。
  - `dance_normal`：普通跳舞，无限制。
  - `start_shooting`：开始射击，必须在射击场坐标范围内使用。
  - `archery_ready`：射箭预备动作，必须在体育馆射箭区域使用。
  - `drink_coffee`：饮用咖啡，仅可在咖啡厅内使用。
  - `gym_exercise`：健身训练，仅可在健身房内使用。
- `buy_item`：购买商品技能，参数需包含 `item_id` 和 `pay_type`（金币/钻石），仅可在道具商店、咖啡厅触发。
- `use_prop`：使用道具技能，参数需包含 `prop_id`，全地图无坐标限制。

## 3. 游戏活动与玩法数据
- 射击打靶活动（ID: `act_shooting_01`）：位于射击场 (125,0,65)。参与条件玩家等级≥LV6，每次参与消耗60金币，单局耗时约2分钟。产出120竞技积分、少量经验值，积分可兑换枪械外观、稀有动作装扮。适合在线时间短、愿意小额消费的休闲玩家。
- 射箭竞技活动（ID: `act_archery_02`）：位于体育馆 (138,0,78)。参与条件玩家等级≥LV5，无需金币消耗，每次消耗15体力值，单局耗时约3分钟。产出敏捷属性经验、80竞技积分。适合零氪玩家、追求角色数值成长的玩家。
- 健身塑形活动（ID: `act_gym_03`）：位于健身房 (108,0,76)。参与需持有健身房月卡道具，无额外金币消耗，每次消耗20体力，单次耗时约5分钟。产出体质属性大量经验、健身专属称号碎片。适合长期在线、养成角色属性的玩家。
- 休闲咖啡打卡（ID: `act_cafe_04`）：位于咖啡厅 (112,0,82)。无等级门槛，购买咖啡后可参与，消耗15金币，耗时约1分钟。产出少量心情值、社交好感度。适合社交休闲、碎片化上线玩家。
- 主城闲逛互动（ID: `act_walk_05`）：位于主城广场 (86,0,62)。无任何参与条件、无消耗，无固定耗时。产出微量在线积分，适合挂机闲逛、等待好友组队场景。

## 4. 经济系统（货币与商品）数据
游戏主要使用**金币、竞技积分、钻石、体力值**四类资源。
金币：每日在线时长、完成日常任务、参与各类玩法均可获取；
竞技积分：参与射击、射箭等竞技类活动专属产出；
钻石：仅通过任务成就、充值渠道获取，可等价兑换金币；
体力值：每5分钟自动恢复1点，上限100点，参与养成类玩法需消耗。

积分兑换规则：每消耗1金币参与玩法可累计0.2竞技积分，钻石可1:100直接兑换金币。
