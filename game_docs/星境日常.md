## 一、游戏基础设定

### 1.1 游戏定位

《星境日常》是一款主打“全场景生活模拟”的元宇宙游戏，无固定剧情主线，核心玩法为模拟现实生活中的各类场景，玩家可自由创建虚拟角色（自定义形象、性格、职业），在虚拟世界“星境城”中体验工作、社交、休闲、学习、购物、居住等一系列真实生活场景，游戏时间与现实时间联动，开放规则贴合现实作息，兼顾趣味性与沉浸感。

### 1.2 角色与世界观

玩家初始创建角色时，可选择不同职业（如教师、医生、程序员、店主、自由职业者等），不同职业对应不同的日常作息与玩法场景；星境城分为多个功能区域（居住区、工作区、休闲区、学习区、商业区、自然景区），每个区域的开放时间与现实场景对应，部分区域有专属时段限制。

### 1.3 核心特色

- 时间联动：游戏内时间与现实时间1:1同步，开放时间贴合现实作息（如工作区仅工作日开放、休闲区夜间开放时间延长）；

- 全场景模拟：覆盖生活全维度，从日常通勤、上班工作，到周末休闲、好友聚会、购物消费，还原真实生活场景；

- 自由交互：玩家可与其他玩家实时社交、组队互动，也可与游戏内NPC进行交互，完成日常任务、获取道具；

- 动态事件：每日随机触发生活类动态事件（如加班、好友邀约、临时活动），事件触发时间与现实时段匹配。

## 二、游戏开放时间详情

### 2.1 基础开放时间（全玩家通用）

游戏整体开放时间：**每日00:00-24:00**（全年无休），但各功能区域、玩法的开放时间有所差异，具体如下：

|功能区域|开放时间|备注|
|---|---|---|
|居住区|00:00-24:00|玩家可随时回到自己的虚拟住宅，进行休息、装修、存放道具|
|工作区|工作日（周一至周五）09:00-18:00|周末及法定节假日关闭，特殊职业（如急诊医生）可在指定时段值班|
|学习区|每日08:00-22:00|包含虚拟课堂、图书馆，可进行学习任务、获取技能点数|
|商业区|每日10:00-22:00|包含超市、商场、餐厅等，20:00后部分餐厅推出夜间特惠|
|休闲区（公园、健身房等）|每日06:00-23:00|夏季（6-8月）延长至24:00，冬季（12-2月）提前至22:00|
|自然景区|每日07:00-19:00|雨雪天气临时关闭，可在游戏内查看实时天气预告|
### 2.2 特殊活动开放时间

游戏每日、每周、每月会推出各类生活类特殊活动，开放时间固定，具体如下：

- 每日活动：早餐特惠（07:00-09:00，商业区餐厅可领取免费早餐）、晚间健身（19:00-21:00，健身房双倍技能点数）；

- 每周活动：周末集市（周六、周日10:00-16:00，商业区广场开放，玩家可摆摊、购物）、好友聚会（周日14:00-18:00，可组队参与互动游戏）；

- 每月活动：月度集市（每月最后一个周六10:00-20:00）、职业技能大赛（每月15日14:00-17:00，对应职业玩家可参与，赢取道具奖励）；

- 节假日活动：法定节假日（如春节、国庆、中秋）会推出专属活动，开放时间为节假日全天，具体活动内容可在游戏内公告查看。

### 2.3 特殊情况开放调整

1. 维护开放调整：每周三凌晨02:00-04:00进行服务器维护，维护期间游戏临时关闭，维护结束后正常开放，维护后可领取维护补偿；

2. 紧急关闭：若出现服务器故障、bug等问题，游戏会临时关闭，关闭时间会通过游戏内公告、官方公众号通知，故障解决后立即开放；

3. 个性化开放：玩家可通过升级虚拟住宅，解锁“私人休闲区”，私人区域可设置自定义开放时间，仅自己或好友可进入。

## 三、核心玩法及场景说明

### 3.1 日常玩法（贴合开放时间）

- 工作日玩法：09:00前通勤至工作区，完成工作任务（不同职业任务不同，如程序员写代码、教师上课），12:00-13:00为午休时间，可前往商业区餐厅就餐，18:00下班后可前往休闲区放松、购物，22:00后可回到居住区休息；

- 周末玩法：可自由安排时间，前往自然景区游玩、商业区购物、学习区提升技能，或参与周末集市、好友聚会等活动；

- 夜间玩法：20:00后，商业区部分餐厅、休闲区（如酒吧、电影院）开放，玩家可进行夜间社交、休闲活动，23:00后大部分区域关闭，仅居住区、部分应急场所开放。

### 3.2 核心场景细节

1. 工作区：不同职业的工作时间略有差异，如医生（白班09:00-17:00，夜班19:00-07:00，轮班制）、教师（08:30-17:30，含午休），工作期间不可随意离开工作区，否则视为旷工；

2. 商业区：10:00开门，22:00关门，每日20:00后部分店铺推出折扣活动，超市21:30后生鲜类商品降价；

3. 学习区：图书馆08:00开放，22:00关闭，可借阅虚拟书籍、参与线上课程，19:00-21:00有公益讲座，参与可获取技能奖励。

## 四、常见问题

- Q1：《星境日常》每天几点开放？答：游戏整体每日00:00-24:00开放，各功能区域开放时间不同（如工作区仅周一至周五09:00-18:00开放）；

- Q2：周末可以去工作区上班吗？答：不可以，工作区仅工作日（周一至周五）开放，周末及法定节假日关闭，特殊职业除外；

- Q3：夜间可以去自然景区吗？答：不可以，自然景区每日19:00关闭，夜间不开放，雨雪天气也会临时关闭；

- Q4：每周三游戏为什么进不去？答：每周三凌晨02:00-04:00是服务器维护时间，维护期间游戏临时关闭，维护结束后可正常进入；

- Q5：周末集市什么时候开放？答：周末集市每周六、周日10:00-16:00在商业区广场开放，玩家可摆摊、购物；

- Q6：游戏突然关闭怎么办？答：可能是服务器故障或紧急维护，可关注游戏内公告、官方公众号，等待故障解决后重新进入，重启游戏即可。
