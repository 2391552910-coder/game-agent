## 1. 项目概述

myAgent v2.0 是一个**多租户游戏玩家行为分析与预测平台**。游戏服务器通过 Webhook 发送玩家离线事件，平台自动获取玩家数据，结合 RAG 知识库检索和 LLM 推理，生成结构化的行为分析和推荐行动。

### 核心技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| API | FastAPI + Uvicorn | HTTP 接口，异步框架 |
| Agent | LangGraph | 有状态图编排，6 节点线性流程 |
| RAG | LightRAG | 混合检索（向量 + 图谱 + 关键词） |
| 向量库 | Milvus | 语义向量存储与检索 |
| 图数据库 | Neo4j | 知识图谱存储 |
| 缓存 | Redis | 认证缓存、去重、限流、健康追踪 |
| 数据库 | PostgreSQL | 租户、配额、分析结果 |
| 包管理 | uv | Python 依赖管理 |

### 四层架构

```
┌─────────────────────────────────────────────────────────────┐
│  API 层 (FastAPI)                                           │
│  认证中间件 / 限流中间件 / Webhook 路由 / Analysis 路由       │
├─────────────────────────────────────────────────────────────┤
│  调度层 (asyncio + Redis)                                    │
│  离线分析调度 / Redis 去重防抖                                │
├─────────────────────────────────────────────────────────────┤
│  Agent 层 (LangGraph)                                        │
│  6 节点 StateGraph：fetch → rag → gather → analyze → reason → merge │
├─────────────────────────────────────────────────────────────┤
│  引擎层 (LightRAG + Storage)                                 │
│  Milvus 向量 / Neo4j 图谱 / Redis 缓存 / PostgreSQL 业务数据  │
└─────────────────────────────────────────────────────────────┘
```

#### 4. 结果持久化 (src/core/infrastructure/result_store.py)

SHA256 快照去重 + 分析结果存储：

```python
import hashlib
from sqlalchemy import select
from .db import get_session, AsyncSession

async def store_analysis_result(
    tenant_id: str,
    user_id: str,
    snapshot: dict,
    output: dict,
) -> UUID:
    # 计算快照哈希
    snapshot_bytes = json.dumps(snapshot, sort_keys=True).encode()
    snapshot_hash = hashlib.sha256(snapshot_bytes).hexdigest()

    async with get_session() as session:
        # 检查是否已存在相同快照的分析结果
        stmt = select(AnalysisResult).where(
            AnalysisResult.tenant_id == tenant_id,
            AnalysisResult.user_id == user_id,
            AnalysisResult.snapshot_hash == snapshot_hash,
        )
        existing = await session.scalar(stmt)

        if existing:
            return existing.id

        # 存储新结果
        result = AnalysisResult(
            tenant_id=tenant_id,
            user_id=user_id,
            snapshot_hash=snapshot_hash,
            output_json=output,
            analyzed_at=datetime.now(timezone.utc),
        )
        session.add(result)
        return result.id
```

#### 5. 熔断器 (src/core/infrastructure/resilience.py)

```python
from tenacity import retry, stop_after_attempt, wait_exponential

# 重试装饰器
@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=1, max=10),
)
async def with_retry(func, *args, **kwargs):
    return await func(*args, **kwargs)

# 熔断器状态
class CircuitBreaker:
    def __init__(self, failure_threshold=5, recovery_timeout=3600):
        self.failure_count = 0
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.last_failure_time = None
        self.state = "closed"  # closed, open, half_open

    def record_success(self):
        self.failure_count = 0
        self.state = "closed"

    def record_failure(self):
        self.failure_count += 1
        if self.failure_count >= self.failure_threshold:
            self.state = "open"
            self.last_failure_time = time.time()
```

**日期**: 2026-04-03

#### 1. 状态定义 (src/core/agents/state.py)

```python
from typing import TypedDict, Annotated
import operator

class AnalysisState(TypedDict):
    user_id: str                              # 玩家 ID
    tenant_id: str                             # 租户 ID（隔离）
    snapshot: dict                             # 玩家快照数据
    rag_context: str                           # RAG 检索结果
    enriched_context: str                      # 工具收集的额外上下文
    behavior_report: str                       # 行为分析 JSON
    reasoned_actions: Annotated[list[dict], operator.add]  # 推理行动（追加）
    final_output: dict                         # 最终组装结果
    errors: Annotated[list[str], operator.add]             # 错误收集（追加）
```

#### 2. 节点实现 (src/core/agents/nodes.py)

6 个节点的线性流程：

```python
# Node 1: fetch_snapshot
async def fetch_snapshot(state: AnalysisState) -> AnalysisState:
    """验证快照非空"""
    if not state.get("snapshot"):
        raise ValueError("Snapshot is empty")
    return state

# Node 2: retrieve_rag_context
async def retrieve_rag_context(state: AnalysisState) -> AnalysisState:
    """从快照构建查询，LightRAG hybrid 检索"""
    query = _build_rag_query(state["snapshot"])
    rag_result = await rag.aquery(query, mode="hybrid")
    return {"rag_context": rag_result}

# Node 3: gather_context
async def gather_context(state: AnalysisState) -> AnalysisState:
    """LLM 自主调用工具收集上下文（最多 3 轮）"""
    # 工具: query_player_history, query_similar_players, dynamic_rag_query
    context = await llm_with_tools.astream(
        messages=[...],
        tools=tools,
    )
    return {"enriched_context": context}

# Node 4: behavior_analysis
async def behavior_analysis(state: AnalysisState) -> AnalysisState:
    """快速 LLM + 结构化输出 → BehaviorProfile"""
    profile = await fast_llm.with_structured_output(BehaviorProfile).ainvoke(
        messages=[...],
    )
    return {"behavior_report": profile.model_dump_json()}

# Node 5: action_reasoning
async def action_reasoning(state: AnalysisState) -> AnalysisState:
    """主力 LLM + 结构化输出 → ActionList"""
    actions = await default_llm.with_structured_output(ActionList).ainvoke(
        messages=[...],
    )
    return {"reasoned_actions": [a.model_dump() for a in actions.actions]}

# Node 6: merge_output
async def merge_output(state: AnalysisState) -> AnalysisState:
    """组装 PlayerAnalysisOutput"""
    output = PlayerAnalysisOutput(
        player_profile=BehaviorProfile.model_validate_json(state["behavior_report"]),
        recommended_actions=state["reasoned_actions"],
        analyzed_at=datetime.now(timezone.utc),
    )
    return {"final_output": output.model_dump()}
```

#### 3. 工具集 (src/core/agents/tools.py)

```python
def create_tools(tenant_id: str, user_id: str):
    """工厂函数，闭包注入租户和用户上下文"""

    @tool
    def query_player_history() -> str:
        """查询该玩家的历史分析记录"""
        return db.query(
            AnalysisResult,
            tenant_id=tenant_id,
            user_id=user_id,
            limit=5,
        )

    @tool
    def query_similar_players(playstyle: str, engagement_level: str) -> str:
        """查询同租户下相似玩家"""
        return db.query(
            AnalysisResult,
            tenant_id=tenant_id,
            filter={"playstyle": playstyle},
            limit=10,
        )

    @tool
    def dynamic_rag_query(query: str) -> str:
        """动态查询知识库"""
        return rag.aquery(query, mode="hybrid")

    return [query_player_history, query_similar_players, dynamic_rag_query]
```

#### 4. 图编排 (src/core/agents/orchestrator.py)

```python
from langgraph.graph import StateGraph, END

def build_orchestrator():
    builder = StateGraph(AnalysisState)

    # 添加节点
    builder.add_node("fetch_snapshot", fetch_snapshot)
    builder.add_node("retrieve_rag_context", retrieve_rag_context)
    builder.add_node("gather_context", gather_context)
    builder.add_node("behavior_analysis", behavior_analysis)
    builder.add_node("action_reasoning", action_reasoning)
    builder.add_node("merge_output", merge_output)

    # 线性边
    builder.add_edge("fetch_snapshot", "retrieve_rag_context")
    builder.add_edge("retrieve_rag_context", "gather_context")
    builder.add_edge("gather_context", "behavior_analysis")
    builder.add_edge("behavior_analysis", "action_reasoning")
    builder.add_edge("action_reasoning", "merge_output")
    builder.add_edge("merge_output", END)

    # 设置入口
    builder.set_entry_point("fetch_snapshot")

    return builder.compile()
```

#### 决策点

- **为什么用 operator.add reducer**: reasoned_actions 和 errors 使用追加模式，确保多轮调用不会覆盖前序结果
- **为什么两个 LLM 模型**: fast_model 用于收集上下文和分析（低延迟），default_model 用于最终推理（高质量）
- **为什么用 with_structured_output**: 避免 LLM 返回非法 JSON，确保输出可解析

#### 调度逻辑 (src/core/scheduler/triggers.py)

```python
import asyncio
from redis.asyncio import Redis

# Redis 去重键前缀
DEBOUNCE_KEY_PREFIX = "debounce:"

# .pending_tasks 存储待执行任务
_pending_tasks: dict[str, asyncio.Task] = {}

async def schedule_offline_analysis(
    tenant_id: str,
    user_id: str,
    snapshot: dict,
) -> str:
    """调度离线分析，使用 Redis SET NX 原子去重"""
    redis = await get_redis()
    debounce_key = f"{DEBOUNCE_KEY_PREFIX}{tenant_id}:{user_id}"

    # 尝试获取锁（TTL 300 秒）
    acquired = await redis.set(
        debounce_key,
        "1",
        nx=True,  # 仅当不存在时设置
        ex=300,   # 5 分钟过期
    )

    if not acquired:
        return "duplicate"  # 已有待处理任务

    # 创建后台任务
    task = asyncio.create_task(
        _run_analysis_background(tenant_id, user_id, snapshot),
    )
    _pending_tasks[f"{tenant_id}:{user_id}"] = task

    return "scheduled"

async def _run_analysis_background(
    tenant_id: str,
    user_id: str,
    snapshot: dict,
):
    """后台执行分析"""
    try:
        orchestrator = create_orchestrator()
        initial_state = AnalysisState(
            user_id=user_id,
            tenant_id=tenant_id,
            snapshot=snapshot,
            rag_context="",
            enriched_context="",
            behavior_report="",
            reasoned_actions=[],
            final_output={},
            errors=[],
        )
        result = await orchestrator.ainvoke(initial_state)
        await store_analysis_result(tenant_id, user_id, snapshot, result["final_output"])
    finally:
        # 清理任务记录
        task_key = f"{tenant_id}:{user_id}"
        _pending_tasks.pop(task_key, None)

def cancel_offline_analysis(tenant_id: str, user_id: str) -> bool:
    """取消待执行的离线分析"""
    task_key = f"{tenant_id}:{user_id}"
    task = _pending_tasks.get(task_key)
    if task:
        task.cancel()
        del _pending_tasks[task_key]
        return True
    return False
```

#### 决策点

- **为什么用 asyncio.create_task 而不是 Prefect**: 减少外部依赖，更低的调度延迟，更适合秒级响应场景
- **为什么用 Redis SET NX**: 原子操作，避免 TOCTOU（Time-of-check to Time-of-use）竞态条件
- **为什么 TTL 5 分钟**: 玩家反复上下线时，5 分钟内的离线只分析一次

```python
from starlette.middleware.base import BaseHTTPMiddleware
from fastapi import Request, HTTPException

class AuthMiddleware(BaseHTTPMiddleware):
    """API Key 认证中间件"""

    EXEMPT_PATHS = {"/docs", "/openapi.json", "/health", "/api/v1/tenants/register"}

    async def dispatch(self, request: Request, call_next):
        if request.url.path in self.EXEMPT_PATHS:
            return await call_next(request)

        api_key = request.headers.get("X-API-Key")
        if not api_key:
            raise HTTPException(status_code=401, detail="Missing API Key")

        # 验证 API Key（Redis 缓存 → PostgreSQL）
        tenant = await validate_api_key(api_key)
        if not tenant:
            raise HTTPException(status_code=401, detail="Invalid API Key")

        request.state.tenant = tenant
        return await call_next(request)
```

#### 2. 限流中间件

Redis ZSET 滑动窗口算法：

```python
class RateLimitMiddleware(BaseHTTPMiddleware):
    """滑动窗口限流：100 req/min per tenant"""

    WINDOW_SIZE = 60  # 秒
    MAX_REQUESTS = 100

    async def dispatch(self, request: Request, call_next):
        tenant = getattr(request.state, "tenant", None)
        if tenant:
            key = f"rate_limit:{tenant.id}"
            now = time.time()
            redis = await get_redis()

            # 移除过期记录
            await redis.zremrangebyscore(key, 0, now - self.WINDOW_SIZE)

            # 计算当前请求数
            count = await redis.zcard(key)
            if count >= self.MAX_REQUESTS:
                raise HTTPException(status_code=429, detail="Rate limit exceeded")

            # 添加当前请求
            await redis.zadd(key, {str(now): now})
            await redis.expire(key, self.WINDOW_SIZE)

        return await call_next(request)
```

```python
@router.get("/api/v1/analysis/{user_id}/latest")
async def get_latest_analysis(request: Request, user_id: str):
    """获取玩家最新分析结果"""
    tenant = request.state.tenant

    async with get_session() as session:
        stmt = select(AnalysisResult).where(
            AnalysisResult.tenant_id == tenant.id,
            AnalysisResult.user_id == user_id,
        ).order_by(AnalysisResult.analyzed_at.desc()).limit(1)

        result = await session.scalar(stmt)
        if not result:
            raise HTTPException(status_code=404, detail="No analysis found")

        return result.output_json
```

#### 决策点

- **为什么用 Redis ZSET 做限流**: 滑动窗口比固定窗口更精确，避免边界突刺
- **为什么 X-API-Key 在 Header 而不是 Body**: RESTful 最佳实践，幂等操作不改变资源
- **为什么 Webhook 立即返回**: 分析是异步的，Webhook 只负责触发调度

#### 2. 负载均衡器 (src/core/llm/balancer.py)

```python
import random
from .models import LLMProviderConfig

class LLMBalancer:
    """加权轮询 + 健康降级"""

    def __init__(self, providers: list[LLMProviderConfig]):
        self.providers = providers
        self.current_index = 0
        self.health_scores: dict[str, int] = {p.id: 0 for p in providers}

    def select(self) -> LLMProviderConfig | None:
        """选择健康的 provider"""
        # 过滤不健康（连续失败 >= 5）
        healthy = [
            p for p in self.providers
            if p.is_active and self.health_scores[p.id] < 5
        ]

        if not healthy:
            return None

        # 加权轮询
        total_weight = sum(p.weight for p in healthy)
        rand = random.randint(1, total_weight)

        cumulative = 0
        for p in healthy:
            cumulative += p.weight
            if rand <= cumulative:
                return p

        return healthy[-1]

    def record_success(self, provider_id: str):
        """成功调用，重置健康分数"""
        self.health_scores[provider_id] = 0

    def record_failure(self, provider_id: str):
        """失败调用，增加健康分数"""
        self.health_scores[provider_id] = self.health_scores.get(provider_id, 0) + 1
```
