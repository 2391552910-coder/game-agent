维度	    HTTP	                                     WebSocket
协议层级	应用层	                                       应用层
底层承载	TCP	                                          TCP
通信模型	半双工：只能客户端主动请求，服务端被动响应	         全双工：客户端、服务端可随时互相发消息
连接形态	短连接，请求完毕立即断开	                      长连接，一次握手后连接常驻
端口	   80/443	                                     复用 80/443，握手基于 HTTP 升级

HTTP：（当前，webhook）
客户端发请求
服务端返回响应
连接立刻断开
下次交互重新走一遍

WebSocket：
先用 HTTP 完成协议升级握手
同一条 TCP 连接保持不断
双方随时收发消息
主动关闭才断连
